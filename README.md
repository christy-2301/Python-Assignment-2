Python Assignment 2 – Data Structures & Conditional Statements

Overview

- List indexing and slicing
- Dictionaries
- Sets

- Conditional statements (if, elif, else)

Tools Used

Assignment Tasks

- Use conditional statements to categorize scores

Learning Outcome
